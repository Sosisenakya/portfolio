Open source · Luau

Whisper

A wrapper around Roblox's MessagingService for talking between servers. It takes care of the rate limits and edge cases so you just queue a message and listen for it, fully type-checked

  • Priority queue urgent messages go out first, add your own levels
  • Auto batching packs several messages into one payload to stay under the rate limits
  • Middleware compress, encrypt or filter data on the way in or out
  • Retries and de-duplication failed sends retry, repeated messages are dropped
  • Safe shutdown pending messages are flushed before the server closes
  • Zero dependencies install with Wally or drop the folder in
